# 别用价格把产品做成一样的

来源：Jon McNeill（前特斯拉总裁，后任 Lyft 首席运营官，DVx Ventures）。本站依据访谈转述整理，没有原片链接，数字都是他本人说的。

## When to use
- 对手在降价，你准备跟着降，或者已经在比谁更便宜。

## When not to use
- 你还说不清这周要改的那一件具体的事。先把事情写具体，再跑这份。

## Required inputs
- 产品是什么：{{产品}}
- 你准备怎么改价格：{{价格动作}}
- 客户现在不选你就会失去什么：{{差异}}

## The framework
Jon McNeill 说，Lyft 在一轮用户流失潮里把份额做大并上市，但和 Uber 很早就开始比价格。产品变成谁都能换的东西，两边毛利都不好。份额涨了，不代表这门生意更值钱。

## Workflow
1. 看 {{价格动作}}：它是在买一次份额，还是在让 {{产品}} 更难被换掉。
2. 用 {{差异}} 检验。如果客户换走只是少花一点钱，这个差异还不够。
3. 建议这周做或不做这个价格动作。要做，写明停的条件。
4. 写出一个不靠降价的动作，让客户换走时会丢掉东西。

## Failure patterns
- 把份额增长当成生意变好。
- 对手一降价就跟着降。
- 说不出客户留下的理由，除了便宜。

## Output format
- 这周降不降：降 / 不降
- 原因，最多 4 句
- 如果降，什么时候必须停
- 不靠价格的那一个动作
