# 五问：你到底怎么赢

来源：Roger Martin，《Playing to Win》。https://www.youtube.com/watch?v=y7SN4FK8noY

## When to use
- 战略会上每个人都同意愿景，但下周排期对不上。

## When not to use
- 你还没跟 5 个目标客户谈过。先去谈，再写战略。

## Required inputs
- 愿景：{{愿景}}
- 客户：{{客户}}
- 现状：{{现状}}
- 能力：{{能力}}

## The framework
战略是一组合在一起的选择。五问：赢的标准是什么？在哪玩？怎么赢？要有哪些对手没有的能力？要配什么管理机制？保护自己只有两条路：不一样，或成本更低。站在中间没有位置。

## Workflow
1. 用 {{愿景}} 写一句赢的标准，必须能在一年后判断对错。
2. 用 {{客户}} 写在哪玩。同时写出你拒绝的相邻客群。
3. 对照 {{现状}}，选择怎么赢：更不一样，或更便宜。只能选一个主路径。
4. 检查 {{能力}} 是否真是对手短期抄不走的。不是的话，标成待补，不要当成已有优势。
5. 写这季度的管理机制：谁每周看哪个数字，什么情况叫停。

## Failure patterns
- 五问都答成“我们要做最好的产品”。
- 又要差异化又要全市场最低价。

## Output format
- 五问，每问一句
- 明确不做什么
- 这季度每周看的一个数字
