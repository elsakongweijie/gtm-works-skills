# 你在产品市场匹配的哪一层

来源：Todd Jackson（First Round）。四层：萌芽、发展、强、极端。三件东西：需求、满意、效率。一开始不要三件一起追。极端匹配要三者都在，而且能持续交付；只有满意和需求、没有效率，业务到不了规模。https://www.youtube.com/watch?v=yc1Uwhfxacs

## When to use
- 你需要决定这季度该追满意、需求，还是效率。

## When not to use
- 你还说不清谁是那三到五个客户。先回去找人，不要套层级。

## Required inputs
- 真正满意的客户大概几家：{{客户数}}
- 新客户从哪来：{{需求从哪来}}
- 团队这月主要在优化什么：{{你在优化}}

## The framework
萌芽：先让大约三到五家客户对一个很痛的问题满意。满意第一，需求第二，效率可以差，只要能换来那种满意。需求多半来自你认识的人。发展：从大约五家做到大约二十五家，开始要有一个不靠熟人的需求来源，效率指标还不是焦点。强：需求会来找你，至少一个渠道能放大，这时效率才进入焦点，同时不能让满意退步。极端：需求、满意、效率都站得住。新的产品线要重新找匹配，不会自动继承。

## Workflow
1. 只用 {{客户数}} 和 {{需求从哪来}} 选一层：熟人里的几家是萌芽；开始有可重复的非熟人来源是发展；人会找上门是强。不要因为融过资就往上抬。
2. 对照这一层该优先的那一件，看 {{你在优化}} 是否抢跑。抢跑的写下来停。
3. 萌芽却没人会非常失望：问题选错或人找错，不要加渠道。
4. 发展却仍只有熟人：这周只建一个不靠介绍的来源，不看毛利。
5. 写这一层的完成线，完成前不加下一层的指标。

## Failure patterns
- 五个客户时就拿烧钱倍数考核。
- 有了收入就宣布已经匹配。
- 三件一起列为本月 OKR。

## Output format
- 你在哪一层
- 这层只优化的一件
- 这月停掉的指标
- 怎样算可以进下一层
