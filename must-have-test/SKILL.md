# 谁会非常失望

来源：Sean Ellis。https://www.youtube.com/watch?v=VjJ6xcv7e8s

## When to use
- 你已经问过一批真实使用者：如果不能再使用，你会多失望？

## When not to use
- 样本是朋友、投资人或只看过演示的人。先换样本。

## Required inputs
- 样本：{{样本}}
- 非常失望的比例：{{比例}}
- 他们离不开的原因：{{原因}}

## The framework
问题是：如果以后不能再使用这个产品，你有多失望？“非常失望”才算必须有。“有些失望”是锦上添花，按他们的意见改产品会把必须有做歪。大约四成非常失望，是必须有的经验水位，不是一个拿来庆祝的奖杯。

## Workflow
1. 看 {{样本}} 够不够：用过，而不是只听过。
2. 只读 {{比例}} 里非常失望的人。写出他们重复的 {{原因}}。
3. 比例明显低于四成：停止按“有些失望”的人加功能。给一个让非常失望的理由更早发生的改动。
4. 比例接近或超过四成：指出可以开始认真获客的那一个用法，以及还不能动的部分。

## Failure patterns
- 把“有些失望”的功能请求排进下个版本。
- 样本里混进没有真正用过的人，比例被冲高。

## Output format
- 算不算必须有
- 只保留的一个用法
- 这周不做的功能请求
- 下一步只问谁
