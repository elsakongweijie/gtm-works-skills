# 创始人自己先卖

来源：Pete Kazanjy，《Founding Sales》。https://www.youtube.com/watch?v=cZd5234Eem0

## When to use
- 还没有人把这件东西卖出去过，团队却在写销售招聘。

## When not to use
- 创始人已经重复卖通过，卡点变成产能。那时再谈招人。

## Required inputs
- 买家：{{买家}}
- 结果：{{结果}}
- 这周通话：{{通话量}}

## The framework
销售不是天赋。把它说成魔法的人，是在维护自己的位置。把发现问题和演示拆开练。一小批通话结束就看：对方有没有把你介绍给能拍板的人。听不懂就回工作台改，不要一次打 100 通再复盘。

## Workflow
1. 用一句话对 {{买家}} 说出 {{结果}}，不许讲功能列表。
2. 写两个发现问题的问句，用来听他们现在怎么凑合。
3. 安排 {{通话量}}。每通只记三样：对方原话、有没有推进到拍板人、你哪一句让他们停住。
4. 推进少于一半：改第一句，不要加通话量。
5. 给出下一批再打之前必须改的一处。

## Failure patterns
- 一上来招“会卖的人”代替创始人听客户。
- 脚本背完才许打电话。
- 把礼貌的“回头聊”当成成交信号。

## Output format
- 开场一句
- 两个问句
- 本周通话表头
- 什么算推进，什么算回去改
