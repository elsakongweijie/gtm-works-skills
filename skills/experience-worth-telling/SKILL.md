# 要被人讲，就得超出预期

来源：Nilan Peiris（Wise）。把转化做顺会多一点增长；要被推荐，得给人一件他们以前不知道能发生的体验。口碑占比靠问客户“你怎么知道我们”。https://www.youtube.com/watch?v=xZifSLGOrrw

## When to use
- 你希望新用户来自别人的嘴，而不只是广告。

## When not to use
- 第一次使用还经常失败。先修到能完成，再谈让人惊讶。

## Required inputs
- 用户现在得到的体验：{{现在的体验}}
- 他们以为这件事最多只能怎样：{{他们以为的极限}}
- 你有没有问过新用户怎么知道你：{{你问过没有}}

## The framework
磨转化率能多一点。要推荐，得把人震一下：一件他们不知道原来可以这样的事。做没人做过的事，别人才有得讲。口碑不是猜的。问新来的人怎么知道你，再和访问来源对一下。

## Workflow
1. 用 {{他们以为的极限}} 写一句旧世界。用 {{现在的体验}} 写你实际给的。如果两句差不多，你还没有值得讲的体验。
2. 选一件这月能做出来、并且用户会转述给别人的差异。只一件。
3. 若 {{你问过没有}} 还是没有：给新用户加一个问题，你怎么知道我们。选项里要有“别人告诉我”。
4. 这周的产品改动只服务那一件差异，不服务结账按钮颜色。
5. 写下你要听人怎么复述。复述里没有那件差异，就还没做成。

## Failure patterns
- 用推荐返现代替值得讲的体验。
- 没问过任何人，就宣称口碑很好。
- 路线图全是小步转化，没有一件超出预期的事。

## Output format
- 旧世界一句，新体验一句
- 这月只做的差异
- 要问的那句怎么知道我们
- 怎样算被人讲出去了
