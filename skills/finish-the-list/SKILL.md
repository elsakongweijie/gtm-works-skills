# 先打完旧名单，再要新的

来源：Jon McNeill（前特斯拉总裁，后任 Lyft 首席运营官，DVx Ventures）。本站依据访谈转述整理，没有原片链接，数字都是他本人说的。

## When to use
- 想加投放或加人找客户，但已经来过的人没有被跟完。

## When not to use
- 你还说不清这周要改的那一件具体的事。先把事情写具体，再跑这份。

## Required inputs
- 产品是什么：{{产品}}
- 已经来过、还没跟完的人：{{旧名单}}
- 你想马上做的获客动作：{{新动作}}

## The framework
Jon McNeill 说，特斯拉当时当季说要交大约一万两千辆，季中只卖出约三千辆。试驾的人没有被回访。他们暂停新名单，先把旧的联系完，订单才进来。营销预算被要求是零，公司还要每六到八个月翻一倍。速度来自把已经举手的人做完，不是先把漏斗灌满。

## Workflow
1. 看 {{旧名单}}：这些人来过吗？有人联系过吗？结果记了吗？
2. 若没联系完：指出 {{新动作}} 里哪些只是在加新名字，建议这周停。
3. 给 {{产品}} 写这周的联系节奏：每天联系多少人、问哪三个问题、什么情况才算跟完。
4. 写出重新打开新名单的条件。旧的没跟完，不加预算。

## Failure patterns
- 用新广告掩盖没人回访。
- 把「发过一封邮件」当成跟完。
- 没有记录谁约过、谁没买、为什么停。

## Output format
- 这周能不能要新名单：能 / 不能
- 原因，最多 4 句
- 旧名单怎么打完：每天多少、问什么、怎样算完
- 重新打开新名单的条件
