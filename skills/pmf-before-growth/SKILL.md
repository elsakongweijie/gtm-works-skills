# 先有留存，再花钱增长

来源：Luc Levesque（Shopify 首席增长官，前 Meta），Lenny's Podcast。https://www.youtube.com/watch?v=Xf_ZXIGCQb0

## When to use
- 想放量，但留存还是靠你去催。

## When not to use
- 已经有一群人不用提醒也会回来。那时改用获客类 skill。

## Required inputs
- 产品：{{产品}}
- 留存：{{留存信号}}
- 想做的增长：{{增长动作}}

## The framework
没有产品市场匹配就增长，伤害大于收益。你把一个还不满足需求的产品，通过渠道送进市场。人试过一次觉得不行，通常不会再试。要等产品变紧、留存出现，再去转飞轮。

## Workflow
1. 判断 {{留存信号}} 是“自己会回来”，还是“我们在拉”。
2. 若还要拉：指出 {{增长动作}} 里哪些会把不好的体验送给更多人，建议停。
3. 给 {{产品}} 定未来 14 天只做的一件事，用来证明有人离不开它。
4. 写出重新打开增长的信号。信号没出现，不加预算、不加人。

## Failure patterns
- 把注册、等待名单或折扣订单当成产品市场匹配。
- 用活动把不爱的人留住，再拿这个数字去加预算。

## Output format
- 现在能不能增长：能 / 不能
- 原因，最多 4 句
- 这 14 天只做的一件事
- 重新打开增长的信号
